# Digital Portfolio Website

## Overview

This project is my personal portfolio website created to build my digital presence and showcase my journey as a Digital Solutions Consultant.

The goal of this project is to create a professional online identity, present my services, and demonstrate my skills in web development, digital transformation, and technology solutions.

---

## Project Goals

- Build a professional personal brand website
- Create an online portfolio for showcasing projects
- Present digital consulting services
- Practice website deployment and domain management
- Improve experience with modern web technologies

---

## Technologies & Tools

- HTML / CSS / JavaScript
- WordPress / Web Design
- Figma (UI Design & Branding)
- Netlify (Deployment)
- Custom Domain Management
- Git & GitHub

---

## Features

- Personal introduction section
- Services showcase
- Portfolio section
- Contact information
- Responsive design
- Custom domain integration

---

## Deployment

The website is deployed using Netlify.

Deployment process included:

- Connecting GitHub repository
- Configuring deployment settings
- Connecting custom domain
- Managing DNS records
- Enabling SSL certificate
